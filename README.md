# Prompt Library

Публичная библиотека повторно используемых шаблонов промптов.

## Содержание

- [Technical Task Writer v1.0](prompts/technical-task-writer/README.md)

## Принципы оформления

Каждая карточка промпта содержит:

- название;
- версию;
- владельца;
- теги;
- цель;
- шаблон;
- пример входа и выхода;
- три тест-кейса.

Владелец библиотеки: Олег Махалов.
